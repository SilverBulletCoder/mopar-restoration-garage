# Publication and contribution rules

- Everything in this repository is public.
- Vehicle claims, procedures, and technical specifications must be checked before presenting them as confirmed.
- Publish a tutorial derived from private notes only after owner approval and privacy review.
- Do not publish secrets, home address/location clues, private camera or network details, personally identifying details, unredacted chats, or copyrighted scans/manuals without permission.
- Do not commit raw video footage or large video files. Approved YouTube links can be embedded instead.
- Mark sponsorships and affiliate links clearly when introduced.
- Never automatically synchronize the private repository into this repository.
