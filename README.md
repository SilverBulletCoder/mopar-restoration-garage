# Mopar Restoration Garage

A public website and educational project documenting classic Mopar restorations and how AI is used to plan, research, troubleshoot, and share the work.

## Vehicles
- 1973 Plymouth 'Cuda — featured restoration
- 1957 Dodge D100
- 1974 Dodge W100

## Site
This repository contains a proposed Astro static website. Deployment to Cloudflare Pages is not yet configured.

### Local development
```sh
npm install
npm run dev
```

### Production build
```sh
npm run build
```

Output directory: `dist/`.
